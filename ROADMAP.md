# ROADMAP — DimArch Sage v2

Миграция компонентов на палитру `colors/palette.json` v2.0.0.

`palette.json` — источник истины. Правки цвета начинаются там, дальше расходятся
по компонентам. Порядок шагов не случаен: сначала проверяются решения, которые
влияют на всё остальное, и только потом идёт массовая раскатка.

## Шаг 1 — проверить два решения глазами

Оба меняют облик системы целиком, поэтому идут до раскатки. Пока не подтверждены,
остальные шаги делать не нужно.

### 1.1 Фон 180°

- [ ] Временно выставить `bg_panel` в `waybar/style.css` → `rgba(13, 25, 25, 0.78)`
- [ ] Пожить полдня, посмотреть на разных обоях и при разном освещении
- [ ] Решить: 180° (`#0d1919`), назад на 190° (`#0d1719`), или промежуточные 185°

Что проверяем: уходит ли синева, не появляется ли ощущение хаки. Прошлый откат
(`#181e1a`) менял хюи, светлоту и насыщенность одновременно — чистый сдвиг хюи
не пробовали ни разу. Контраст равноценен (12.67 → 12.49), решает только характер.

### 1.2 ANSI blue → лишайник

- [ ] В `ghostty/config.ghostty` заменить `palette = 4=#6ba88c` → `#91b06d`
      и `palette = 12=#7bbc9c` → `#afc992`
- [ ] Посмотреть в деле: `ls` в директориях, inline-код в Claude Code, markdown-ссылки
- [ ] Решить: принять лишайник или вернуть sage

Что проверяем: сейчас blue и green сидят на одном хюи (152° и 153°) — директории
почти сливаются с исполняемыми файлами. Лишайник даёт разнос 65°. Это изменение
с глобальным охватом: ANSI blue используется всеми программами в терминале.

**Если 1.1 или 1.2 отклоняются — откатить соответствующие значения в `palette.json`
до раскатки, а не после.**

## Шаг 2 — линтер

- [ ] `tools/lint-palette.py` — сверяет каждый hex в `dimarch` со значениями палитры
- [ ] Понимает все нотации: `#rrggbb`, `rrggbb`, `#RRGGBB`, `rgba(r,g,b,a)`,
      `rgba(rrggbbaa)`, `0xAARRGGBB`, десятичный `rgba(127,184,158,0.35)`
- [ ] Репортит: чужой цвет, файл, строка, ближайший токен палитры
- [ ] Игнор-лист для законных исключений (вендорные темы, градиенты логотипа)

Почему линтер, а не генератор: правило «palette.json — source of truth» уже
существовало и не работало, потому что файл физически ни к чему не подключён.
Линтер ловит ровно тот дрейф, который накопился, стоит вечер работы и не мешает
подбирать цвета глазами. Генератор имеет смысл собирать, когда палитра устоится.

Нижняя панель — это **не второй waybar**, а самостоятельное приложение
(Python + GTK4, репозиторий `dmitrax/dimarch-taskbar`). Waybar запускает один
экземпляр из `config-top.jsonc`; правила `window#waybar.bottom` в его стилях
мёртвые и помечены как таковые.

- [ ] Подключить палитру: GTK4 читает `:root` custom properties, то есть
      `sage-dark.css` можно подключить напрямую через `@import`
- [ ] Решить хюи фона: `chrome.panel_bottom` оставлен на 190°, тогда как верхняя
      панель ушла на 180°. Сдвиг верхней оказался невидимым, поэтому тащить его
      в нетемизированный компонент заранее смысла нет — решать на живом глазу
- [ ] Роли: активная задача → `ui.fill` + `ui.accent`, свёрнутая →
      `text.tertiary`, требующая внимания → `status.urgent`
- [ ] После этого — удалить мёртвый CSS из `waybar/style.css`
      (`window#waybar.bottom`, `#custom-taskbar` с четырьмя состояниями,
      `#custom-workspace-indicator`, `@define-color bg_panel_bottom`).
      Сейчас он оставлен намеренно: это единственная существующая стилизация
      нижней панели и полезный референс при темизации таскбара.

## Открытые вопросы

**Где хранить `dimarch/CLAUDE.md`.** Файл в `.gitignore`, то есть не переживёт
переустановку. Часть накопленных в нём решений — единственная их запись.

**Генератор.** После того как палитра устоится и линтер покажет реальный объём
ручной синхронизации, станет видно, окупается ли он. Восемь нотаций, прямой
`@import` возможен только у части компонентов (ghostty `config-file`, mpv `include`,
hyprlock `source`, rofi `@import`, CSS `@import`, swayimg `require`); yazi, herdr,
uosc, vscode требуют генерации.

**Светлая тема.** Пока живёт только в Obsidian. `sage-light.css` содержит полный
набор акцентов — они понадобятся, когда дойдёт до SDDM и Firefox.
